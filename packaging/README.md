# HeyMelody for Windows

这是使用 Avalonia 和 FluentAvalonia 界面的 OPPO Enco X4 社区 Windows 客户端。当前版本 0.7.0 保留已有界面，独立后台常驻托盘，主界面通过事件订阅接收耳机状态。版本见 `manifest.json` 和应用设置。支持电量、降噪、五种声音预设、十段自定义 EQ、双设备连接、游戏模式、空间音频和 Hi-Res。其他型号会先核对产品编号；目前只有 X4 的设置开放。

完整解压后，双击 `Start-HeyMelody.cmd`。启动器自动选择 x64、ARM64 或 x86；也可直接打开对应目录中的 `HeyMelody.exe`。三个版本自带 .NET 运行时，无须安装 SDK。支持 Windows 11，程序按当前用户权限运行。

有效设备名单为空时会打开设备管理器。勾选至少一台已配对的传统蓝牙音频设备后保存，主界面只显示这些设备；未连接的已配对设备也可以勾选。没有有效旧名单时取消或关闭管理器会退出主界面，后台托盘保留。以后可在应用设置中选择“管理设备”；有未保存的 EQ 时先确认丢弃。管理器取消保留旧名单，保存后更新设备栏。后台监听已配对设备的连接与解除配对事件，主界面“+”打开 Windows 蓝牙设置。独立管理器为同目录中的 `HeyMelody.DeviceManager.exe`，Windows 11 22H2 以上使用 Mica Alt，其余系统使用主题实色背景。

底部设备卡片内的图标与文字整体居中，设备和末尾“+”在空间足够时整组居中。设备较多时可使用鼠标滚轮、触控板或滚动条横向浏览，“+”随设备一同滚动。打开窗口、切换设备和调整窗口宽度时，选中设备尽量居中；到达列表首尾时自然停在边界，设备完整显示，不添加额外空白。手动滚动后会保留当前位置。

选中名为 OPPO Enco X4 或 Enco X4 的设备后，即使尚未连接控制会话，也会显示 X4 产品图和耳机图标。名称识别忽略大小写及首尾空格；连接后读取的实际型号优先，其他型号使用通用图形。图片识别只用于外观，设置仍需连接并核实设备型号。

先在 Windows 蓝牙设置中配对并连接耳机，再保存白名单。后台自动监听所有白名单中的已连接受支持耳机，界面选择只决定当前显示和设置目标。“断开客户端”暂停所选耳机的控制监听，“连接耳机”恢复；暂停持续到手动恢复或后台重启。界面接收 RFCOMM 通知与 BLE 广播，手动刷新及设置前后确认仍读取耳机状态；提交期间只限制同组的提交按钮或开关，选项和 EQ 编辑仍可调整，其他组仍可提交，应用设置也可打开。空间音频与 Hi-Res 共用一组，预设和自定义 EQ 共用一组。应用后会读取耳机确认；后续手机修改仍会同步到界面。后台通信中断后会重新订阅；后台重启时旧设置请求不会重发，需要重新选择设备并确认状态。

同一用户目标最多尝试两次。连接和设备身份可确认的安全设置失败后，会先读取最新状态；目标已达到则不再发送，否则最多自动重试一次。需要用户决定的再次写入会弹出“确认 / 取消”，默认取消。取消再次写入或首次空间音频/Hi-Res 联动确认，会丢弃全部待选设置、未保存 EQ 和尚未开始的写入，并完整刷新耳机实际状态。取消切换条目、切换/断开耳机或关闭窗口的草稿丢弃确认，会保留草稿。第二次失败会弹出仅有“确定”的提醒，关闭提醒后立即刷新设备信息；明确断连或无法取得完整后台结果时，第一次就提醒并刷新，不自动重试。

十段 EQ 可以选用已保存的条目，或新建并保存。移动滑块后点击“保存均衡器”会保存并选用该条目；“启用此 EQ”只选用已有且无未保存调整的条目。未保存的调整在刷新和其他设置提交期间保留，提交后继续编辑的内容也会保留；恢复、确认丢弃或上述写入取消会清除相应草稿。新建范围为官方客户端的 -6 至 +6 dB，已有条目沿用耳机返回的范围。名称使用中文、英文字母或数字。

空间音频与 Hi-Res 在 X4 上互斥，切换前会提示；可能短暂断开音频。双连关闭会影响第二台设备。游戏模式是耳机的游戏设置，声音延迟并未测量。充电盒未返回电量、未知状态或通信失败会显示“未读取/未确认”，不会猜测百分比。

关闭主界面会结束界面进程，后台继续运行。右键托盘只有“打开主界面”和“退出”；退出会先确认现有 EQ 草稿，取消则继续运行。直接运行 backend/HeyMelody.Host.exe 只启动托盘。本版本不添加登录自启，也没有独立开盖弹窗；后台已提供开盖事件。BLE 广播可补充新鲜电量和后台盒盖观测，不据此启用设置；当前界面没有盒盖状态控件。操作记录仅保存在本次窗口内，前后端通过当前用户和登录会话的命名管道通信，设备地址不进入操作记录。本包不修改 Windows 驱动、注册表、签名或启动配置。原有 LHDC Manager 继续用于驱动和实际音频格式管理。

OTA、录音、翻译和健康功能留待后续阶段。ARM64 当前是交叉构建，真实 ARM64 蓝牙运行仍需在 ARM 电脑上验证。源码离线检查与原生窗口测试使用模拟设备；静态包报告验证架构、图标、依赖和许可，不证明耳机控制。实际硬件执行范围以匹配本版本及可执行文件哈希的报告为准；未附该报告表示硬件行为尚未验证。请求接受和状态回读不等于音频延迟、实际码率、2.3 Mbps 无损或声学输出测量。
