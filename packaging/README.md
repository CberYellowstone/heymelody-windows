# HeyMelody for Windows 0.8.11

0.8.11 修复游戏音效开关与类型的独立写入、失败后的状态回读及控件恢复。游戏音效类型按所选资源来源、固件条件和耳机读回能力提供；Hi-Res 与空间音效分别提交，不再显示互斥限制或自动关闭另一项。右侧降噪恢复为默认展开的 Expander，可手动折叠，刷新时保留展开状态。

0.8.10 统一隐藏“自动音量”（原厂“智能音量调节”），不再查询或设置该项，相关通知不会联动刷新其他设置。旧缓存和 Demo 也不显示此开关。Free4、X3、X4 的反馈为没有此功能；其他机型待确认。右上提示现在说明具体原因，通知订阅不完整时仍可手动刷新，不再误报为设置已禁用。

0.8.9 重新设计“耳塞贴合度测试”和“设置黄金听感”窗口。窗口上部使用 Windows 11 的 Mica Alt 材质（旧系统为主题实色），底部为固定操作栏。黄金听感按“耳道扫描 → 听音测试”分步显示，测听页分左右耳两组显示 12 段进度，当前频段为半满；拖动音量条找到“滴滴”声刚好消失的位置后点“下一步”。结果页可切换原音与黄金听感试听，再命名并保存启用。贴合度结果分别显示左右耳的“贴合良好 / 一般 / 较差”，并给出调整建议。测试流程、确认与停止逻辑与上一版相同。

0.8.8 整理主界面右侧控制面板：设备名称左侧的圆点以绿、黄、灰表示已连接、正在连接或写入、未连接；名称、状态与连接按钮固定在顶部，连接时不再显示固件版本，未连接时在名称下方显示上次连接时间。进度条占用固定位置，出现和消失不会移动下方控件。各设置卡片补齐图标与说明，功能开关按原生设置行对齐，电量卡显示左右耳、充电盒图标及充电标记。

0.8.7 保留默认 GPU 优先渲染、已保存的软件选择及软件回退。底部设备列表显示统一的通用耳机图标，不使用 Enco X4 专属图片；设备信息的“复制”按钮位于展开内容底部。设备状态刷新时保持当前选择，重启后恢复上次选择的已启用设备。已连接设备的功能、选项与设置值会保存在本地，未连接时显示并禁用这些控件；重新连接读取后刷新功能列表，以反映固件变化。第一次有效连接之前没有功能缓存。降噪常显、其他设置默认折叠及组件间距沿用上一版。

0.8.5 修正软件三维模型过亮、曲面缺少层次的问题：按每个网格实际使用的贴图区域估算金属度、粗糙度和发光参数，并调整软件光照。原始模型和基础色贴图保持不变；拖动、惯性和空闲自转继续可用。GPU 模式恢复原始材质与原有光照，自动模式实际退回软件时同样使用修正。

0.8.4 修正 Enco X4 在两种资源来源下的主图：产品旋转采用官方动态 WebP，按原始帧时长播放并正确合成局部帧；捏耳机柄、滑动等 Lottie 操作教程不再作为产品展示。外观提示和已验证资源持续保留，重新打开界面或断连时继续显示已取得的美术。

应用设置提供“三维模型 GPU 加速”，当前默认开启；已有明确关闭选择继续保留。关闭时使用软件后端显示三维模型，并保留拖动、惯性和空闲自转；保存开关后即时应用，无须重启。设置还提供“重新下载在线资源”，校验新资源后替换，失败时保留现有资源。骁龙 8cx Gen 3 的实际兼容性仍需在对应硬件复测。

0.8.3 检查包修复降噪主模式切换：圆形按钮使用父模式编号，自适应的“更少噪音 / 标准 / 更多噪音”仍独立调整子档。仅回读到父模式时不猜选子档。Enco X4 自适应提示音效果待用户真机确认；请对比手机控制，从关闭、通透和手动降噪分别进入自适应，并检查其他主模式与子档声音。

保留 0.8.2 新增的布局演示设备，使用 Enco Free4 丹拿版官方三维模型，以及 0.8.1 的耳机控制连接初始化及错误提示修复。

使用 0.8.11 前，请先关闭旧版主窗口，再从托盘菜单退出旧版后台。完整解压后运行 `Start-HeyMelody.cmd`，使用包内新版主窗口和 Host，游戏音效及 Hi-Res／空间音效修复才会生效；仅替换主窗口仍会连接已经驻留的旧后台。

这是采用 Avalonia 和 FluentAvalonia 的社区 Windows 耳机客户端。资源目录覆盖欢律的 85 个、无线耳机的 141 个耳机产品 ID；配置、协议与实际设备能力共同决定可用功能，未知控制不会开放。OPPO、OnePlus、realme 耳机目录已纳入，音箱排除。

完整解压后双击 **`Start-HeyMelody.cmd`**，启动器选择 x64、x86 或 ARM64 目录中的程序。发布包自带 .NET 运行时，无须安装 SDK；单架构包仅包含所选架构。先在 Windows 中配对并连接耳机，随后通过设备管理器保存名单。管理器、贴合度测试和黄金听感向导分别为 `HeyMelody.DeviceManager.exe`、`HeyMelody.FitTest.exe`、`HeyMelody.HearingSetup.exe`，从主界面打开，共享托盘后台。

检查 Demo：在主界面长按底部设备添加键“+”满 2 秒，添加并选中 `Demo · Enco Free4 丹拿版`。重复长按仍为同一台，短击仍打开 Windows 蓝牙设置。Demo 加载全部已实现主界面控件，可展开设置并在本地调整开关、选项、Slider、文本和 EQ；测试按钮只显示演示反馈。关闭主窗口后 Demo 自动移除，不影响真实设备。没有已配置耳机时，双击 **`Start-3D-Demo.cmd`** 可直接进入同一离线 Demo，不需要白名单或网络。模型默认 GPU 优先，支持拖动旋转、惯性及空闲自转。

设置默认使用欢律、开启在线资源。切换“无线耳机”后整体使用该来源的参数和美术，不混合两套配置。自定义密钥留空时，本版使用对应预置密钥。关闭在线资源后不发起网络请求，保留已下载的有效新版。更新先校验新包、切换引用，再删除旧在线版本；软件预装资源不清理。设置和缓存加密密钥以用户本地 JSON 明文保存。

降噪模式由圆形按钮选择，下方显示细分选项；均衡器频段、预设和可保存方案数由设备决定。修改自定义 EQ 后选择“保存并启用”。耳塞贴合度测试需要双耳正确佩戴。黄金听感下拉框选择本机向导保存及耳机当前完整读回的方案；没有方案时先打开设置向导。校准中可以取消；断连、摘下耳机、关闭窗口等情况会停止测试。

关闭主界面后后台继续运行，右键托盘可打开主界面或退出。直接启动 `backend/HeyMelody.Host.exe` 只启动后台。本版本不添加登录自启或开盖弹窗。Demo 的合成控件集合只供布局检查，不代表丹拿版实机能力。

`ResourceBundles`、各程序 DLL、原生渲染库、`backend` 和 `licenses` 都是运行所需文件，请保留完整目录。资源来自用户提供的 APK 和已验证的官方资源包，版权及源摘要见 `SOURCE-NOTES.md`、`PACKAGE-NOTICES.json`、`ResourceBundles/provenance.json` 和 `licenses/upstream/Extracted-Earphone-Resources-NOTICE.txt`。

模拟协议、界面测试及三架构静态检查不证明所有型号实机、手机并发或 ARM64 硬件行为。具体构建信息见 `manifest.json`；只有与版本、文件摘要匹配的执行记录才能证明对应包的实机验证。
