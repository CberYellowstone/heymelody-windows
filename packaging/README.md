# HeyMelody for Windows

这是使用 Avalonia 和 FluentAvalonia 界面的 OPPO Enco X4 社区 Windows 客户端。本轮范围为迁移 Windows 上已有的 X4 功能。版本见 `manifest.json`。支持电量、降噪、五种声音预设、十段自定义 EQ、双设备连接、游戏模式、空间音频和 Hi-Res。其他型号会先核对产品编号；目前只有 X4 的设置开放。

完整解压后，双击 `Start-HeyMelody.cmd`。启动器自动选择 x64、ARM64 或 x86；也可直接打开对应目录中的 `HeyMelody.exe`。三个版本自带 .NET 运行时，无须安装 SDK。支持 Windows 11，程序按当前用户权限运行。

先在 Windows 蓝牙设置中配对并连接耳机，在客户端选择耳机后点击“连接耳机”。后台每隔八秒读取状态。各设置只在你明确操作时发送；应用后会读取耳机确认。后台通信中断后，点击“刷新设备”再重新连接，确认当前状态后继续操作。

十段 EQ 可以选用已保存的条目，或新建并保存。移动滑块后需要点击“保存均衡器”；未保存的调整会保留到你选择恢复、切换或关闭。新建范围为官方客户端的 -6 至 +6 dB，已有条目沿用耳机返回的范围。名称使用中文、英文字母或数字。保存时会启用该条目。

空间音频与 Hi-Res 在 X4 上互斥，切换前会提示；可能短暂断开音频。双连关闭会影响第二台设备。游戏模式是耳机的游戏设置，声音延迟并未测量。充电盒未返回电量、未知状态或通信失败会显示“未读取/未确认”，不会猜测百分比。

操作记录仅保存在本次窗口内。后台通过私有标准输入/输出通信，设备地址不进入操作记录。本包不修改 Windows 驱动、注册表、签名或启动配置。原有 LHDC Manager 继续用于驱动和实际音频格式管理。

OTA、录音、翻译和健康功能留待后续阶段。ARM64 当前是交叉构建，真实 ARM64 蓝牙运行仍需在 ARM 电脑上验证。实际执行范围以本版本专属的验证报告为准；未附报告表示仅完成构建。请求接受和状态回读不等于音频延迟、实际码率、2.3 Mbps 无损或声学输出测量。

各架构目录的 `LICENSE.txt` 和 `THIRD-PARTY-NOTICES.txt` 为 .NET 运行时许可；`licenses/` 和 `PACKAGE-NOTICES.json` 记录实际还原的 Avalonia、FluentAvalonia 及原生图形库等包的许可。来源说明见 `SOURCE-NOTES.md`。
