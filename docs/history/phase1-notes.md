# 阶段 1：只读控制会话

2026-10-06 完成 0.1.0 的 Windows 只读 CLI、协议库和 RFCOMM 传输库，目标为精确匹配 Product ID `06EC10` 的 OPPO Enco X4。本阶段不实现 GUI、耳机设置或驱动配置。当前入口及实现见[仓库说明](../../REPOSITORY.md)；本页不验证后来的托盘后台或发布包。

成功查询开始于 2026-10-05 15:58:18 UTC。八项 GET 均匹配响应命令和本次序号，业务 status=0，并通过各自布局校验。

固件版本保留原始三元组。Hi-Res 状态与 codec 编号不能替代驱动参数、AVDTP 协商、实际无损或听感证明。该阶段没有播放、重连或开启 Hi-Res；开发中修正了能力位图长度及二进制版本的解析，最终成功结论不包含此前失败尝试。

发现只枚举 Windows 已记忆设备，并查询精确服务；目标须已连接，型号不符即停止。普通帧使用 AA、ULEB128 长度、控制字节及可选分片序号，内层保留 command、sequence、LE16 payload 长度，不添加普通 CRC。长度和分片数量有界，FSN 顺序及载荷声明严格校验。

发送范围为 `0100/0101/0102/0103/0104/0105/010D/0114`；除 `010D [01,18]` 外均为空载荷。未提交 SET、OTA、通知注册、时间应答或主机能力宣告。超时、畸形响应、空 ACK 或断连后不再发送，也不自动重发。报告中的发送记录是应用提交证据，不能等同独立 HCI 抓包。

Debug/Release 编译均零警告、零错误，24 项协议测试和 17 项会话测试通过；Windows ABI 结构大小与偏移检查、PowerShell 5.1 枚举及实际 RFCOMM 八项查询通过。ARM64 仅完成交叉构建，未执行真实蓝牙。最终新增解析边界经离线回归，没有重复实机查询。
