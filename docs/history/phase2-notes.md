# 阶段 2：协议基础与 X4 配置模型

2026-10-06 完成 0.2.0 只读 CLI，报告 schemaVersion=2。保留阶段 1 的八个 GET 策略，没有执行设置、空间关闭、重连或音频验证。本页记录当时结果；当前实现见[仓库说明](../../REPOSITORY.md)。

协议补齐 EOF 完整性检查：半帧、未结束长度或未收完分片均拒绝。FSN 必须连续，不能接受孤立末片、跳序或超出 256 片的回绕。同一连接分配 0..255 序号且不复用，第 257 次请求不发送；响应必须同时匹配命令和序号。

能力表由 APK 的 69 位映射及对应 smali 数组核对，另加入 11 条基础命令。X4 样本的 16 字节位图解析出 92 条命令，含 `0419`，没有未知置位。集合包含 SET 只是设备声明，不扩大只读发送范围；未知尾位只记录，不猜测命令。功能值仅 0/1 映射为开关，其他值保留原值和未知状态。

配置只按精确 Product ID `06EC10` 匹配，不凭名称或别名猜测。嵌入配置与历史证据包中的内置兼容白名单逐字节一致，SHA256 为 `95fcb16e291d5e8c3669745a20907d80c6f21a9d3982dcf1a22587e263dbf0db`；加载时验证该摘要。此阶段未重做 AES-GCM 解密，文件摘要不被当作厂商数字签名。
