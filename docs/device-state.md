# 设备选择与离线控件

设备列表刷新只更新同一设备的名称、连接状态及外观提示，不代表用户取消选择。主界面以设备身份保留当前选择，并在 Avalonia 完成列表绑定后恢复当前列表中的选中项与高亮。内部空选择不会触发切换；实际切换及丢弃 EQ 草稿确认后仍会验证目标设备存在。

Host 保存上次由主窗口选择的真实设备，使用与白名单相同的稳定摘要键，不保存蓝牙地址或临时会话 ID。恢复时先保留当前设备，再选择上次记住的已启用设备，最后回退到列表第一项。没有设备时不覆盖记录；演示、预览、管理时的临时空选择和取消切换不覆盖真实设备偏好。

## 离线展示

偏好与缓存保存在白名单目录下的 `device-state.json`，默认路径为 `%LOCALAPPDATA%/HeyMelody/device-state.json`。schema 2 缓存仅保存欢律展示，按设备键隔离，包含型号、颜色、固件、ANC 模式与子选项、EQ 预设与自定义条目及频段、空间音频选项、连接与音频设置、动态功能分组的完整标签、范围和当前值，以及听感配置和读取时间。未提交草稿不落盘；缓存不授予控制权限。

设备断连或后台暂时不可用时，保留当前设备的缓存控件，仍能展开设置查看，但禁止设备操作并取消待提交写入。0.8.8 起不再显示缓存提示信息条：页头状态点为灰色，设备名称下方显示“上次连接”及该缓存的读取时间；正在重新建立控制连接时显示“正在连接…”并以黄色圆点标示。电量、盒盖及佩戴状态只使用当前有效观测，缓存不会生成开盖通知或被当作实时蓝牙状态。

重新连接后重新读取当前设备，完整替换缓存，包括固件新增或删除的功能。失败连接不会用空列表覆盖历史功能，不同设备的快照不会混用。旧 schema 1 文件仅迁移明确标记为欢律的条目及首选设备键，其他来源的展示直接弃用，随后原子保存为 schema 2。缓存采用后台合并写入和临时文件原子替换，正常退出等待最后一次保存。缺失、损坏或不兼容文件按无缓存处理；第一次有效连接之前无法恢复历史控件。

## 接口与验证

IPC 使用 schema 4，`UiDevice.IsPreferredSelection` 随现有设备列表传递恢复偏好；`UiSnapshot.PresentationCached` 与可空的 `PresentationSampleTime` 标记缓存展示。会话身份、generation、revision、连接状态、实时观测和写入权限仍由当前后台生成并验证，不能由缓存恢复。

Host 与 Client 回归覆盖稳定选择、完整展示数据、断连禁用、跨后台重启、读取失败、固件功能增删和缓存隔离。App 回归通过实际 ListBox 绑定验证连接状态刷新无需再次点击，名称／排序／外观变动保留高亮，缓存回填不触发 SET，以及离线时页头显示上次连接时间、重新连接后恢复“已连接”与绿色圆点。测试使用模拟设备和内存服务；真实耳机固件升级及原生 ARM64 执行需单独验证。
